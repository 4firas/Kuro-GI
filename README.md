# Kuro

Companion overlay for Android arm64. ESP, a teleport network, an auto-farmer, protection switches. Every switch says what it costs.

- **Wiki + guides:** https://4firas.github.io/Kuro-GI/
- **Download:** [Releases](https://github.com/4firas/Kuro-GI/releases) (verify the SHA-256 before installing)
- **Help:** read the wiki's Help page first; crash records go through the in-app button.

This repo holds the site and the release artifacts. No source is published here.

Full list in the [changelog](https://4firas.github.io/Kuro-GI/changelog.html).

Unofficial fan project. Not affiliated with, endorsed by, or connected to any game publisher. Use at your own risk.
