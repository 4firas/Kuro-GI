v2.3.1

Android arm64, game 7.1.0. 446f8059…f88c93

Auto talk works on 7.1. The game moved the dialogue view inside its own context object, and the old check was quietly refusing the new one. Every line, choice and skip verified in-game after the fix.

Fake weather works on 7.1. The weather system was handed paths five characters long -- the wrong string conversion, silently failing every lookup. It now sends the game's own paths, checked against what the game itself asks for.

Extended reach is back. A switch and a range slider on the World tab (3-40 m). While Auto Loot is on, pick-ups, ore and plants inside the range are collected for you through the game's own action -- items taken from 38-39 m on device. With Auto Loot off it does nothing.

God mode works again. 7.1 asks the question from the other side; the 7.0 check had gone quiet because of it. Blocked hits read Immune again.

Farm page rebuilt. Regions carry their own marks, the item list has real pictures with the count left per row, and one line says where you are.

Scrolling no longer picks. A swipe that starts on a button scrolls instead of choosing it. Drag, and you scroll.

Extended reach is parked. One gate it hangs on needs a rework on 7.1. The switch is out of the menu until that lands, and everything it drove is off with it.

v2.2.2i

Android arm64, game 7.0.0. d62ea107…f8f75d27. Superseded by v2.3.

Crash records rebuilt. Every register, the thread that died, the faulting instruction, a stack scan when the frame chain is dead, and a vitals line every ten seconds — scene, fps, entities, position, memory. Older records are kept instead of overwritten, and the last crash is posted to logcat at launch.

Dialogue crash fixed. The speed hold could write to an animation handle after the character it belonged to was gone — two reports, same stack, speed switch off. The handle is checked before it is ever touched now.

Manual map teleports covered. The reach feed emptied before KURO's own sends only. A waypoint tapped by hand rebuilds the world the same way — entries could survive the rebuild and crash later. It drains before those too now.

Stray tap removed. A leftover debug tap touched the screen once, 16 seconds after login. It is out of the build.

Auto-farm crash fixed. A waypoint transmit rebuilds the world around you; the 40 m reach feed could leave entries pointing at things the rebuild destroyed, and the game itself walked them. Entries are now unregistered before the transmit, while everything is still alive.

Quest crash fixed. The game died using quest teleport. The marker resolves safely now.

Quest teleport goes direct. No more waiting on a waypoint that was never going to help. One jump.

Oculi auto-close. An offline oculi point that lands you metres off now pulls you onto the live one by itself.

Health readout. Settings shows game base, hooks, entities and ESP state, so dead-feature reports take seconds.

Auto farm moves to Auto. The whole offline-points farm now lives on the Auto page, open by default, in plainer words. Teleport keeps GO, picked items and the quest marker.

Domain-exit crash fixed. Leaving a domain could die in the reach feed, which kept working the old scene through the loading screen. It sits out transitions now.

Quest-marker crash fixed. The marker position is read while the object is alive and never touched again — the map pools marks and kills them between map opens. The previous build called into them after death.

Mid-air grab crash fixed. Collecting at 40 m reach while flying could die the same way with no scene change at all — streaming recycles entities between sighting and touch. Every entity is rechecked before the touch now.

Get it from GitHub releases, not re-uploads.
