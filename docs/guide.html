Install

  1. Download KURO-v2.0.apk from Releases. It is the full client for Android arm64, built for game version 7.0.0 — not a patch, not a plugin.
  2. Verify it before installing: 
    sha256sum KURO-v2.0.apk
# must start with 828b0141 and match the .sha256 file in the release
  3. Install the APK (allow install from unknown sources when asked). Your account is untouched — it's the same login.
  4. Launch and wait for the world to load. The badge appears once everything is hooked — don't press anything before that; early presses misbehave because the hooks aren't in yet.
  5. Tap the badge to open the menu. Quick buttons beside it jump straight to things.
Updating: install the new APK over the old one. Your profiles and collected memory carry over.

First run

  • Open Settings → Safety and read the three pills. Then read Safety once, fully.
  • Turn on No Fall Damage before trying any approximate offline point.
  • Try one Go to nearest → Chest before running a farm, so you know what a landing feels like.
  • Open the in-game map once per region you care about. Kuro harvests the map's own flags (activated vs locked) while it's open, and everything — counts, farm order, transmit choices — gets smarter with it.

Teleporting, properly

One hop

Teleport → Go → nearest chest / waypoint / statue. Short hops are instant. Long ones start with a loading screen (the game's own transmit) and finish on foot — that screen is the safe mile, not a bug. The status line at the top of the page always says what's happening: transmitting…, X m to go, arrived. If a hop ever stops short, read that line — it names the cause.

A locked waypoint

Offline points → region → Teleport Points → Go to nearest. Locked ones are visited too, on purpose: you land next to it and Auto Waypoint presses the prompt. If the game offers no prompt at all, the point is quest-sealed — no tool opens those; the farm skips them.

A full clear

Offline points → region → kind → Auto farm. Set the wait (longer = calmer), watch the top line count collected vs skipped, stop any time. The six switches the run depends on (Auto Waypoint, Auto Statue, reach, While airborne, Auto Loot, Auto Open) are forced on for the run and restored after — however it ends. Collected points are remembered, so tomorrow's run only visits what's left.

Approximate pins (newer regions) arrive high and drop. No Fall Damage on. Every time. No exceptions.

Items

World → Items → pick by name and picture → Nearest picked item to jump to it, Unpick all to clear. Combine with Only picked items to declutter the ESP.

ESP

World → ESP. Ring with picture or symbol, name, distance. Start with names + distance on, arrows on, max distance ~200 m, and narrow by kind under What to mark. Done things stop being counted — if a kind shows zero, move on or Reset visited.

Profiles & harvest

Settings → Profiles saves the whole configuration; keep one for screenshots (hide damage numbers, ESP pretty) and one for farming. Settings → Harvest records what you walk past with a count and a JSON export.
