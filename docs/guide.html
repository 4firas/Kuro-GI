Install

  1. Download KURO-v2.2.apk from Releases. Full client, Android arm64, game version 7.0.0. Not a patch, not a plugin.
  2. Check the hash before installing: 
    sha256sum KURO-v2.2.apk
# starts with 4b38f099, matches the .sha256 in the release
  3. Install it (allow unknown sources when asked). Same login, account untouched.
  4. Launch and wait for the world to load. The badge shows up once the hooks are in. Don't press anything before that. Early presses land before the hooks do and misbehave.
  5. Tap the badge for the menu. The quick buttons beside it jump straight to things.
Updating means installing the new APK over the old one. Profiles and collected memory carry over.

First run

Read Safety once, fully, before touching anything red. Then: No Fall Damage on before any approximate pin. One Go to nearest chest before any farm, so a landing feels familiar. Open the in-game map once per region you care about, since Kuro reads the map's own flags while it's open and everything gets smarter with it.

One hop

Teleport, Go, nearest chest, waypoint or statue. Short hops land instantly. Long ones open with a loading screen (the game's own transmit) and finish on foot. That screen is the safe mile, not a bug. The status line at the top of the page always says what state it's in. If a hop ever stops short, read that line, since it names the cause.

A locked waypoint

Offline points, region, Teleport Points, Go to nearest. Locked ones get visited on purpose. You land next to it and Auto Waypoint presses the prompt. No prompt at all means quest-sealed, so finish the local quest first. Nothing opens those.

A full clear

Offline points, region, kind, Auto farm. Set the wait (longer is calmer) and watch the top line count collected against skipped. Stop any time. The six switches the run needs get forced on for it and restored after, however it ends. Collected points are remembered, so tomorrow's run only visits what's left.

Approximate pins arrive high and drop. No Fall Damage on. Every time.

Items and ESP

World, Items, pick by name and picture. Nearest picked item jumps to it, Unpick all clears. Only picked items declutters the rest. For ESP itself: names and distance on, arrows on, max distance around 200 m, then narrow by kind. A kind showing zero means move on.

Profiles and harvest

Profiles save the whole setup. Keep one for screenshots and one for farming. Harvest records what you walk past, with a count and a JSON export.
